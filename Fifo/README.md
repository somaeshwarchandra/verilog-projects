\# FIFO



\## Overview



A parameterized synchronous FIFO implemented in Verilog HDL for buffering data between modules.



\## Files



\- fifo.v

\- tb\_fifo.v



\## Features



\- Parameterized data width

\- Parameterized FIFO depth

\- Synchronous read and write

\- Full and empty flag generation
