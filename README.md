\# Verilog Projects



A collection of RTL design projects written in Verilog HDL.



\## Projects



\- ALU – 8-bit Arithmetic Logic Unit

\- Register File – 8×8 Register File

\- FIFO – Parameterized Synchronous FIFO

\- UART – UART transmitter, receiver, and loopback verification



\## Built With



\- Verilog HDL

\- Xilinx Vivado

\- Git

\- GitHub
